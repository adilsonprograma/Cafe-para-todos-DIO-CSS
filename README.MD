# Cafe-para-todos-bootstrap
☕ Café Para Todos Este projeto é uma landing page responsiva para uma cafeteria fictícia, desenvolvida com o objetivo de aplicar conceitos avançados de estilização e componentes de interface.

📌 Sobre o Projeto O Café para todos foi desenvolvido como parte prática do curso de CSS Frameworks da plataforma DIO (Digital Innovation One). O projeto foca na criação de uma interface moderna, intuitiva e totalmente responsiva, simulando um ambiente real de cardápio e informações de localização de um estabelecimento.

🚀 Tecnologias Utilizadas Para a construção deste site, foram empregadas as seguintes tecnologias:

HTML5: Estruturação semântica do conteúdo.

CSS3: Estilizações personalizadas para refinamento visual.

Bootstrap 5.8: Framework principal utilizado para agilizar o desenvolvimento de componentes e garantir a responsividade (Grid System, Flexbox).

Google Maps: Para visualizar a localização no modal.

🛠️ Funcionalidades e Componentes O projeto explora diversos componentes do ecossistema Bootstrap para proporcionar uma melhor experiência ao usuário:

Navbar Fixa: Navegação suave entre os frascos da página.

Carrossel de Imagens: Destaque visual com transições dinâmicas.

Sistema de Abas (Tabs): Organização do cardápio por categorias (Expresso, Cappuccino, etc.).

Cartões Responsivos: Exibição elegante dos produtos e proteção.

Modal de Localização: Janela interativa para exibir o endereço e o mapa sem sair da página principal.
